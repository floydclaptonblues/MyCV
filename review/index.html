Reference-model use

cp review/model/config.template.json review/model/config.local.json
# Populate sourced values; leave no required nulls.
python review/model/trajectory_model.py \
  review/model/config.local.json \
  --output-dir review/model/output

cd review/model
python -m unittest -v

The single-run output includes a numerical path, impact point, load factor, bank-adjusted stall speed when available, and a numerical-versus-closed-form comparison. Parameter sweeps write one row per candidate to CSV.

Priority review questions

  1. Can the modeled point be regenerated from records that predate recovery without reading the stored modeled point?
  2. Which terminal-state values are measured, inferred, assumed, or selected after viewing the outcome?
  3. Is the available speed airspeed or ADS-B groundspeed, and is wind applied consistently?
  4. Does the fixed-wing model remain valid near accelerated stall or loss of control?
  5. Was the displayed search ellipse produced from surviving trajectories or selected manually?
  6. Which omitted artifact would most improve confidence in the result?
